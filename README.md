# Крестики-нолики 3×3 с ИИ на Minimax (C#)

Лабораторная работа: искусственный игрок для игры двух участников на алгоритме Minimax
(вариант 1 — крестики-нолики, ИИ никогда не проигрывает).

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 7.0 или новее (сторонние библиотеки не нужны)

## Запуск игры (консоль)

Из папки проекта:

```bash
dotnet run
```

1. Программа спросит, будете ли вы ходить первым (`Y` — да, `n` — нет).
2. Вы играете крестиками `X`, ИИ — ноликами `O`.
3. Чтобы сходить, введите номер клетки:

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

4. После каждого хода ИИ выводит оценку каждого возможного хода и число просмотренных узлов дерева.
5. `q` — выход из игры.

Проект также открывается в Visual Studio / Rider (`MinimaxTicTacToe.csproj`).

## Проверка, что ИИ не проигрывает

```bash
dotnet run -- --test
```

Программа перебирает **все** возможные последовательности ходов человека (при обоих вариантах
очерёдности), ИИ на каждую отвечает своим лучшим ходом. Результат: 642 партии, 0 поражений ИИ.

## Запуск в Unity (необязательно)

Логика игры в `TicTacToe.cs` не зависит от консоли, поэтому её можно перенести в Unity:

1. Скопируйте `TicTacToe.cs` и `Unity/TicTacToeUnity.cs` в папку `Assets/Scripts` Unity-проекта.
2. Создайте на сцене пустой GameObject и добавьте к нему компонент `TicTacToeUnity`.
3. Нажмите Play — поле 3×3 рисуется через `OnGUI`, клик по клетке — ваш ход.
